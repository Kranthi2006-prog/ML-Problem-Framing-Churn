# ML-Problem-Framing-Churn

# ML Problem Framing & Responsible Data Card

## Project

Customer Churn Prediction

## Objective

Determine whether machine learning is justified for predicting customer churn and document the data, risks, safeguards, and fallback strategy before model training.

## Deliverables

### 1. ML Problem-Framing Memo
Defines the decision, prediction target, unit of observation, action window, and non-ML baseline.

### 2. Responsible Data Card
Documents dataset purpose, provenance, population, features, missingness, leakage risks, and safeguards.

### 3. Baseline Notebook
Contains dataset exploration and a non-ML baseline for comparison.

### 4. Risk Register
Documents potential risks, harms, mitigations, monitoring, and rollback conditions.

## Dataset

Customer churn training dataset.
